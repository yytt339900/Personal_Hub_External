Personal Hub

A private, single-user personal organizer.

Personal Hub is a personal tool used only by its owner to keep track of their own ongoing matters, calendar, e-mail and finances in one place. It is not offered to the public and does not accept sign-ups; only the owner's own Google account is connected.

What it does with Google data

  • Gmail (read-only): reads the owner's own message headers and short previews so the owner can see what needs attention. It never sends, deletes or modifies e-mail.
  • Google Calendar (read-only): reads the owner's own events to show upcoming commitments. It never creates, changes or deletes events.

See the privacy policy for how this data is stored and protected.
