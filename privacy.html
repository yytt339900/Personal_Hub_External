Privacy Policy

Personal Hub · Last updated: November 13, 2026

Personal Hub is a private application used by a single person, its owner, for their own accounts only. It has no other users.

Data accessed

With the owner's explicit authorization, Personal Hub reads, read-only:

  • Gmail message metadata (sender, subject, date, labels) and short message previews;
  • Google Calendar events (title, location, time).

It does not request permission to send, modify or delete e-mail or calendar events.

How data is used

The data is used only to show the owner an overview of their own messages, events and tasks. It is not used for advertising, profiling or any purpose other than the owner's personal organization.

Storage and security

Data and access tokens are stored encrypted on a server controlled by the owner, reachable only over the owner's private network. Message bodies and attachments are not stored.

Sharing

Google user data is not sold, shared with, or transferred to any third party. When the owner asks the built-in assistant a question, relevant excerpts may be sent to the AI model provider solely to generate that answer for the owner; this data is not used to train models.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the stored data from their server.

Google API Services User Data Policy

Personal Hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
